# Рефлексия
Использовал Github Spec-kit. Создал первую спеку через `/speckit.specift` - UI меню для игры, затем создал вторую - добавление новых объектов в генерацию мира. Дальше запустил специальный тул для анализа совместимости разных спек `/speckit.analyze`, она написала что все хорошо, спеки друг другу не мешают, надо реализовать вначале первую, затем вторую.

Дальше начал реализацию, вначале `/speckit.plan`, потом `/speckit.tasks`, и затем уже `/speckit.implement` для 1 и потом второй спеки.

В целом процессом остался доволен, понравился такой способ написания фичей, довольно просто, и процесс безопасный - фреймворк обеспечивает корректное выполнение тасок. Узнал собственно как работать с фреймворком Github Spec-kit, и в целом ознакомился с подходом SDD.
